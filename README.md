# Susanna Mamen Velluthottam — Portfolio

Personal portfolio site for Susanna Mamen Velluthottam (Web3/FinTech Product + Ops · ex-Revolut, KPMG · LSE), built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build is written to `dist/`.

## Editing content

All profile content (experience, skills, certifications, education) lives in `src/data.js`. The animated career chart in the hero is `src/components/CareerChart.jsx`.
